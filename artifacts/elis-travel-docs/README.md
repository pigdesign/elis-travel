# Manuale segreteria ElisTravel

Sito di documentazione interno basato su Astro Starlight.

## Sviluppo

```sh
pnpm --filter @workspace/elis-travel-docs dev
```

## Verifica e build

```sh
pnpm --filter @workspace/elis-travel-docs build
```

I contenuti si trovano in `src/content/docs`. Prima della pubblicazione, definire la protezione di accesso perché il sito statico non include autenticazione propria.
