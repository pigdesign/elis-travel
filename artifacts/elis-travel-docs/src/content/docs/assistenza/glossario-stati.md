---
title: Glossario degli stati
description: Significato degli stati usati per richieste, gite e pagamenti.
---

## Gite

| Stato | Significato |
| --- | --- |
| **Bozza** | In preparazione, non pronta alla raccolta adesioni |
| **Aperta** | Accetta prenotazioni |
| **Confermata** | La partenza è stata confermata |
| **Completata** | La gita si è conclusa |
| **Annullata** | La partenza non avrà luogo |

## Richieste

| Stato | Significato |
| --- | --- |
| **Nuova** | Da prendere in carico |
| **Contattata** | Primo contatto effettuato |
| **Preventivo inviato** | Proposta già inviata |
| **Vinta** | Trattativa conclusa positivamente |
| **Persa** | Trattativa non conclusa |

## Prenotazioni e pagamenti

| Stato | Significato operativo |
| --- | --- |
| **In attesa** | Nessun pagamento ancora confermato |
| **Carta in attesa** | Il pagamento con carta non è concluso |
| **Carta da salvare** | È richiesta la registrazione della carta per un addebito successivo |
| **Richiesta acconto** | È stato richiesto l’acconto |
| **Acconto** | Acconto registrato, saldo ancora dovuto |
| **Carta salvata** | Metodo predisposto, non equivale a saldo pagato |
| **Richiesta totale** | È richiesto il pagamento dell’intero importo |
| **Saldo richiesto** | La richiesta di saldo è stata inviata |
| **Saldato** | Importo dovuto interamente registrato |
| **Scaduto** | Termine della richiesta superato |
| **Addebito fallito** | Tentativo di pagamento non riuscito |
| **Nessun addebito** | Non è avvenuto alcun addebito |
| **Rimborsato** | Somma prevista restituita integralmente |
| **Rimborso parziale** | È stata restituita solo una parte |

## Azioni amministrative

| Azione | Significato |
| --- | --- |
| **Richiesta di pagamento corretta** | Metodo, importo o scadenza della richiesta sono stati aggiornati |
| **Incasso registrato** | La segreteria ha inserito un pagamento manuale verificato |
| **Incasso stornato** | Una registrazione manuale errata è stata neutralizzata, restando nello storico |

:::note
“Carta salvata” e “Saldato” non sono sinonimi. Per stabilire se una prenotazione è pagata, consulta sempre stato e storico completo.
:::
